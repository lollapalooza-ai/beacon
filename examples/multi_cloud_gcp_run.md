# Example: Multi-Cloud Pipeline Run (GCP + AWS)

This example demonstrates Beacon's multi-cloud orchestration in action. 

In this scenario, Beacon attempts to procure compute for a deep learning workload (`Train ResNet on 4xA100 under $50`). Because both AWS and GCP adapters are configured, it queries both clouds concurrently. The LLM evaluates the options, selects the optimal one, and Beacon proceeds to provision and monitor it.

## 1. Environment Setup

Ensure you have your environment variables set to configure your LLM and Cloud Providers:

```bash
# Enable the local Ollama LLM provider
export BEACON_LLM_PROVIDER="ollama"
export BEACON_LLM_MODEL="llama3"

# Enable the GCP cloud adapter
export BEACON_GCP_PROJECT="project-a2d78296-18ff-4dd4-a6c"

# Set log level to debug to see the multi-cloud engine working
export BEACON_LOG_LEVEL="debug"
```

## 2. Command Execution

Run the beacon workload:

```bash
./beacon run --intent 'Train ResNet on 4xA100 under $50'
```

## 4. Monitoring & Decommission

Once the instance is successfully provisioned and reaches the `running` state, Beacon begins continuously monitoring its health. **Decommissioning does not happen instantly.** The workload remains actively running until either the user aborts it (via `Ctrl+C` / SIGINT) or the requested maximum duration expires.

When a termination signal is triggered, Beacon cleans up the infrastructure gracefully:

```json
{"level":"info","time":"...","message":"Received shutdown signal, decommissioning...","signal":"interrupt"}
{"level":"info","time":"...","message":"State transition","new_state":"decommissioning","old_state":"running","workload":"edca1a52-f4dd-4b57-96fc-1bef3676c614"}
```

## 5. Local State Verification (SQLite)

Beacon maintains a resilient local state file (`beacon.db`). If you query the underlying SQLite database for this specific workload ID while it is running, you will see all the provisioned details. This state allows `beacon recover` to find and terminate orphaned instances if the agent crashes.

```bash
$ sqlite3 beacon.db ".mode line" "SELECT id, intent, state, instance_id, instance_provider, instance_type, instance_region, payment_token_id, budget FROM workloads WHERE id = 'edca1a52-f4dd-4b57-96fc-1bef3676c614';"
```
